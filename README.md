# Suzuka's Dual Support Backpack AIO

Carry a second supported support weapon in your backpack slot in Helldivers 2. Pick up a second weapon while slot 3 is occupied, then press **4** to switch between the two. The package also provides a native backpack HUD bar, guarded empty-tube dropping and cleanup for supported disposable weapons, and limited ammo refill fixes.

## Download and install

Download the latest ZIP from [Releases](https://github.com/Suzuka2788/helldivers-2-dual-support-backpack/releases/latest). Requires **Bingus Shared Loader v15 or newer (API 1)**. Disable previous AIO test builds and the five separate feature mods, install the ZIP in your mod loader, deploy, and restart the game. **F10 is not required.**

## Current limitations

- Ammo refill supports only verified weapons and conditions; it is not a general fix for all backpack weapons.
- Allow disposable weapons to finish dropping before switching weapons.
- Joining another player's multiplayer lobby may cause frame drops, especially before entering a mission.
- Not every weapon and multiplayer combination has been tested.

Logs are under `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs`. To uninstall, quit the game, disable this package in the mod loader, deploy, and restart.

This release uses the same five game Lua resources as the tested `rc2-shared-identity-scan-test` build; the loader display name and bundled readme were updated for release.
